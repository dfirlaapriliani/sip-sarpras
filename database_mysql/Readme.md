# Database MySQL - SIP SARPRAS

Folder ini berisi file database untuk proyek SIP Sarpras.

## Cara Import Database

1. Buka phpMyAdmin atau MySQL client kamu
2. Buat database baru dengan nama: `sip_sarpras`
3. Pilih menu **Import**
4. Pilih file `.sql` yang ada di folder ini
5. Klik **Go** / **Import**

## Informasi Database

- Nama File : new_invex.sql
- Nama Database : new_invex
- Dibuat dengan : phpMyAdmin / MySQL

## Catatan

Pastikan konfigurasi database di file `.env` atau `config/database.php`
sudah disesuaikan dengan pengaturan lokal masing-masing.
