## 📌 Deskripsi
SIP Sarpras adalah aplikasi berbasis web untuk mengelola peminjaman sarana dan prasarana secara digital agar lebih efisien dan terstruktur.

---

## ✨ Features
- Autentikasi (Login, Register, Logout)
- Dashboard sesuai role
- CRUD Data Barang
- Manajemen Kategori
- Sistem Peminjaman & Checkout
- Riwayat Peminjaman
- Laporan
- Role Management
- Log Aktivitas
- Search & Pagination
- Responsive Design

---

## 🛠 Tech Stack
**Frontend** : React.js  
**Backend** : (Laravel / Express.js)  
**Database** : (MySQL / SQLite / PostgreSQL)  
**Styling** : CSS / Tailwind
